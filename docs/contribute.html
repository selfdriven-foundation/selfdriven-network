Contribute

Get in touch.

Have a question, idea, or just want to say hello? We'd love to hear from you. Reach out to the selfdriven team and we'll get back to you as soon as possible.

Ways to contribute

Open source, open door.

All interface code and data model schemas are open source. Log an issue, contribute code, or build and host your own interfaces.

  • selfdriven Network on GitHubThe source for this site and the interface documentation.{% include arrow.html %}
  • selfdriven.techThe interface code — build and host your own human and community interfaces.{% include arrow.html %}
  • Interfaces NodeThe current focus: a decentralised node supporting the network interfaces.{% include arrow.html %}
