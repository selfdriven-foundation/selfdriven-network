The network

From the human to the node, every layer is an interface.

selfdrivenOS is reached through a set of interfaces — human and social at the top, network interfaces in the middle, and storage, compute & connect infrastructure underneath. Each one keeps data protected as close to the human as possible, and shares only the minimum a community needs.

Getting started

Four ways to use the network.

Use what's hosted, call the APIs, build your own, or help run the infrastructure — all on the same Core interface-managed data.

  1. 01 · Use

    Hosted interfaces

    selfdriven.app, levelup, studio, org and wallet, heyOcto.ai, and community spaces on selfdriven.community — each serving a different need on the same data.

  2. 02 · Integrate

    Call the APIs

    Endpoints on *.interface.selfdriven.network. Every method is an HTTP POST with a JSON body over SSL, and every response returns a status of OK or ER.

  3. 03 · Build

    Your own interfaces

    All interface code and data model schemas are open source. Start with selfdriven.tech and the Human Interface Kit to build and host your own.

  4. 04 · Operate

    Cooperative infrastructure

    With selfdriven Services, the network supports cooperative infrastructure — education, resources and participation — from Unity Nodes to the Interfaces Node.
